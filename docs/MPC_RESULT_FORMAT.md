# MPC Result Format

This document describes saved closed-loop MPC result files.

## Locations

Single-run result:

```text
results/mpc/<source>/<scenario>/latestMpcResult.mat
```

Repeated-run results:

```text
results/mpc/<source>/<scenario>/repeatedMpcResults.mat
results/mpc/<source>/<scenario>/bestMpcResult.mat
```

## `latestMpcResult.mat`

Saved variable:

```matlab
mpcResult
```

Fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `version` | scalar | Result-format version. |
| `source` | char | Model/data source, such as `mss` or `usvsimu`. |
| `created_at` | char | Save time. |
| `Ts` | scalar | Sampling time. |
| `t` | 1-by-N double | Time vector. |
| `v` | struct | State logs for each controller. |
| `psi_ref` | struct | Reference heading for each controller. |
| `path_err` | struct | Cross-track error for curve tracking. |
| `ulog` | struct | Control input logs. |
| `t_solve` | struct | QP solve time logs. |
| `wpt` | struct | Reference path or waypoint data. |
| `mode` | char | `heading` or `curve`. |
| `scenario` | char | Scenario name generated by `mpcScenarioName`. |
| `mp_mem` | vector | Payload mass time history. |
| `param` | struct | Full simulation configuration used by the run. |
| `finish_step` | struct | Curve-completion step for each controller. |
| `metrics` | struct | Metrics computed by `computeMpcResultMetrics`. |

## Controller State Logs

`mpcResult.v.<method>` is a `6-by-N` matrix:

| Row | Symbol | Meaning |
| --- | --- | --- |
| 1 | `u` | Surge speed. |
| 2 | `v` | Sway speed. |
| 3 | `r` | Yaw rate. |
| 4 | `x` for MSS; `y` for USV-Simulator | First stored position coordinate. |
| 5 | `y` for MSS; `x` for USV-Simulator | Second stored position coordinate. |
| 6 | `psi` | Heading angle in radians. |

Set `source` correctly when importing external results. The XY plotting panel
uses horizontal Y and vertical X, with a source-specific row mapping.

Current method fields are:

```text
mss
nc
kmeans
gp
fcm
```

Their display labels are defined in `mpcMethodLabel`.

## Control Logs

`mpcResult.ulog.<method>` is a `2-by-N` matrix:

| Row | Symbol | Meaning |
| --- | --- | --- |
| 1 | `tau_X` | Surge force command. |
| 2 | `tau_N` | Yaw moment command. |

`mpcResult.t_solve.<method>` is a `1-by-N` vector in seconds. Non-MPC
baselines may contain zeros or `NaN`, depending on the controller.

## Repeated Results

`repeatedMpcResults.mat` stores:

```matlab
mpcRepeatedResult
```

Fields:

| Field | Meaning |
| --- | --- |
| `version` | Result-format version. |
| `source` | Source name. |
| `scenario` | Scenario name. |
| `created_at` | Save time. |
| `n_runs` | Number of repeated MPC runs. |
| `seeds` | Random seeds used by each run. |
| `run_wall_time_s` | Wall-clock time for each run. |
| `runs{i}.mpcResult` | Full single-run result. |
| `runs{i}.metrics` | Metrics for run `i`. |
| `summary` | Mean/std metric tables across runs. |
| `best_run` | Selected run metadata for the proposed controller. |
| `best_result_file` | Path to `bestMpcResult.mat`. |

## External Environment Logs

To reuse `plotMPCResultFile` with another simulator or ROS environment, save a
`.mat` file containing `mpcResult` with the fields above. Optional fields can
be empty, but the following are required:

```matlab
t, v, psi_ref, path_err, ulog, t_solve, wpt, mode
```
